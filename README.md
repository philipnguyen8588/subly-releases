# Subly — ScreenTranslator

Dịch phụ đề game sang tiếng Việt theo thời gian thực, đọc thành giọng nói và dịch cả màn hình.
Hoạt động với PS5 (qua Remote Play) hoặc bất kỳ cửa sổ nào trên máy Mac.

Đây là trang **tải bản cài đặt**. Mã nguồn không công khai.

## Tải về

Vào mục **Releases** (cột bên phải) và tải file mới nhất.

## Cài trên macOS

1. Giải nén file `.zip`, kéo **ScreenTranslator.app** vào thư mục **Applications**.
2. Lần đầu mở: **chuột phải vào app → Mở → Mở** (app ký bằng chứng chỉ riêng, chưa notarize nên macOS sẽ cảnh báo lần đầu — đây là bình thường).
3. Khi app hỏi quyền **Ghi màn hình**, hãy cho phép rồi mở lại app.
4. Lần đầu chạy, nhập email để đăng ký dùng thử; thiết bị cần được duyệt mới dùng được.
